# Photography and Image Direction

Portfolio imagery must document real work, authorship, collaborators, process, and outcomes. It cannot manufacture evidence an employer might reasonably treat as factual.

## Selection system

Build each case-study sequence from:

1. A clear project or place-setting image.
2. Preston or collaborators performing a documented activity, when permission exists.
3. Artifacts: research, writing, photographs, diagrams, instruments, websites, plans, or deliverables.
4. Context: workshop, airport, venue, studio, geography, audience, or publishing surface.
5. Outcome evidence supported by records.

Record project, people, action, place, date, photographer, source, permission/rights, and edit history. Captions should explain why the image is evidence.

## Generation template — illustration only

Generated imagery may serve as clearly labeled editorial illustration. It may not fabricate a client engagement, team, audience, campaign, award, document, performance, project outcome, or portrait of a real person.

```text
Create a clearly non-documentary editorial illustration for the Preston Wimberly Oxblood portfolio.
Case-study topic: [verified subject]
Purpose: [concept explanation / section divider / abstract social graphic]
Composition: [artifact-led / diagrammatic / abstract], with quiet negative space at [location]
Allowed source facts: [explicit verified facts only]
Palette: warm paper, black ink, restrained oxblood, quiet grey
Character: direct, specific, contemporary editorial craft; square geometry and useful visual hierarchy
Avoid: named-brand imitation, agency-template gloss, fake documents, fake metrics, invented client marks, invented collaborators, fake awards, generic Americana, gradients as atmosphere, and simulated documentary photography
Output: desktop [ratio/dimensions] plus an independently composed mobile version [ratio/dimensions]
Labeling: contemporary illustration—not project evidence
```

## Edit template — preserve evidence

```text
Edit the supplied rights-cleared portfolio photograph non-destructively.
Documented project/person/place: [verified facts]
Required correction: [exposure / white balance / crop / horizon / dust spot]
Preserve exactly: identity, facial features, body position, instruments, tools, screens, documents, venue/workplace details, logos, physical state, and existing environmental evidence
Do not add or remove people, audiences, awards, documents, equipment, client marks, results, or contextual details. Do not simulate film damage, sepia, grain, or flash that is absent from the source.
Crop: desktop [ratio] focal point [x/y]; mobile [ratio] focal point [x/y]
Deliver: master plus web derivative; retain original metadata, permission, and credit
```

# Preston Wimberly Portfolio — Design System

## Direction

Contemporary editorial portfolio: confident, restrained, specific, and tactile. The design should feel like a well-art-directed magazine rather than a generic creative-agency template.

## Palette

| Role | Value |
| --- | --- |
| Paper | `#F1EFE8` |
| Deep paper | `#E5E1D7` |
| Ink | `#151713` |
| Soft ink | `#55594F` |
| Forest | `#172C24` |
| Signal | `#FF5B35` |

Use signal orange for emphasis and conversion moments. Use forest for a single strong inverted section. Avoid gradients, shadows, rounded cards, and generic corporate blue.

## Typography

- Display: Playfair Display, medium weight, tight letter spacing.
- Body and interface: DM Sans.
- Labels: DM Sans, bold uppercase, wide letter spacing.
- Body copy stays at 16px or larger with at least 1.5 line-height.

## Layout

- Asymmetric editorial grids with generous space.
- Full-width photography and clear captioning.
- Hairline rules create rhythm and hierarchy.
- Project pages use a large statement, full-bleed image, then challenge, approach, and deliverables.
- Mobile collapses to one column without horizontal scrolling.

## Interaction

- Touch targets are at least 44px.
- Hover transitions run 150–300ms and do not shift layout.
- Keyboard focus uses a visible orange outline.
- Respect `prefers-reduced-motion`.

## Avoid

- Floating glass cards, pill-heavy UI, mock dashboards, fake metrics, icon clutter, and decorative motion.
- Generic marketing language or unsupported claims.
- Stock-style imagery when real project photography exists.
